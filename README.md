Bug Bounty Tracker

A python project created to learn Python, Git and Github while building a simple bug bounty tracking tool.

Current Features
  Menu system
  User input
  Lists
  Basic conditional logic

Planned Features
  Add bounty targets
  Show bounty targets
  Save targets to file
  Add notes
  Add statuses
  Export reports

Learning Goals
  Improve Python skills
  Improve Git and Github skills
  Build a portfolio project
  Practice software development fundamentals
